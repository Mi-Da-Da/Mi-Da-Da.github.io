栈和队列

栈

基本概念

  • 栈$(Stack)$：只允许在一端进行插入或删除操作的线性表，元素进出特点为后进先出$(LIFO)$。
  • 栈顶：允许插入和删除的一端。
  • 栈底：不允许插入和删除的一端。

基本操作

  • $InitStack(\&S)$：初始化栈，构造一个空栈并分配内存空间。
  • $DestroyStack(\&S)$：销毁栈，销毁并释放栈所占用的内存空间。
  • $Push(\&S,x)$：进栈。若栈未满，则将$x$加入使其成为新的栈顶元素。
  • $Pop(\&S,\&x)$：出栈。若栈非空，则弹出（删除）栈顶元素，并用$x$返回。
  • $GetTop(S,\&x)$：读取栈顶元素。若栈非空，则用$x$返回栈顶元素。
  • $StackEmpty(S)$：判断一个栈是否为空，若为空，则返回$true$，否则返回$false$。

队列

基本概念

  • 队列$(Queue)$：只允许在一端进行插入，在另一端进行删除的线性表，元素进出特点为先进先出$(FIFO)$。
  • 队头：允许删除数据元素的一端。
  • 队尾：允许插入数据元素的一端。

基本操作

  • $InitQueue(\&Q)$：初始化队列，构造一个空队列并分配内存空间。
  • $ClearQueue(\&Q)$：销毁队列，销毁并释放队列所占用的内存空间。
  • $EnQueue(\&Q,x)$：进队列。若队列未满，则将$x$加入使其成为新的队尾元素。
  • $DeQueue(\&Q,x)$：出队列。若队列非空，则弹出（删除）队头元素，并用$x$返回。
  • $GetHead(\&S,\&x)$：读取队头元素。若队列非空，则用$x$返回队头元素。
  • $QueueEmpty(S)$：判断一个队列是否为空，若为空，则返回$true$，否则返回$false$。

  判断队满和队空：

  • 牺牲一个存储单元来区分队空和队满，使用$(Q.rear+1)\%MaxSize == Q.front$作为判断队列是否已满的条件。

  • 结构体中设置$tag$变量记录队列最近的操作，$tag=0$代表删除操作，$tag=1$代表插入操作。当$front==rear{\ }\&\&{\ }tag==0$时，说明队列已空；反之说明队列已满。

双端队列

  • 双端队列：只允许从两端插入，在两端删除的线性表。
  • 输入受限的双端队列：只允许从一端插入，在两端删除的线性表。

栈的应用

括号匹配问题

  • 最后出现的左括号最先被匹配。
  • 遇到左括号就入栈，遇到右括号就消耗一个左括号。
  • 如果所有括号匹配完且栈非空，则说明左括号未闭合；扫描到右括号且栈空，则该右括号未闭合。

表达式求值

  • 中缀表达式：运算符在两个操作数中间，例如$a+b$。一个中缀表达式可能对应多个前缀或后缀表达式。
  • 后缀表达式（逆波兰表达式）：运算符在两个操作数后面，例如$ab+$。
  • 前缀表达式（波兰表达式）：运算符在两个操作数前面，例如$+ab$。

中缀表达式转后缀表达式

  手算过程如下：

  1. 确定中缀表达式中运算符的运算顺序。
  2. 选择下一个运算符，按照【左操作数 右操作数 运算符】的方式组合成新的操作数。
  3. 重复$2$直至全部处理完。
  4. 使用左优先原则，先算左边的运算符，再算右边的，保证机算和手算结果一致。

  机算时，从左往右处理所有元素，可能出现下面三种情况：

  • 遇到操作数，直接加入后缀表达式。
  • 遇到界限符，如果是左括号则直接入栈，如果是右括号则弹出运算符并加入后缀表达式，直到弹出左括号。
  • 遇到运算符，依次弹出栈中优先级高于或等于当前运算符的所有运算符，并加入后缀表达式。若碰到左括号或栈空则停止。之后再将当前运算符入栈。
  • 上述方法处理完所有字符后，将栈中运算符依次弹出，并加入后缀表达式。

中缀表达式转前缀表达式

  手算过程如下：

  1. 确定中缀表达式中运算符的运算顺序。
  2. 选择下一个运算符，按照【运算符 左操作数 右操作数】的方式组合成新的操作数。
  3. 重复$2$直至全部处理完。
  4. 使用右优先原则，先算右边的运算符，再算左边的，保证机算和手算结果一致。

三种表达式的计算

  • 后缀表达式机算：
    1. 从左往右扫描所有元素，遇到操作数和运算符时执行$2$和$3$。
    2. 遇到操作数则入栈，继续执行$1$。
    3. 遇到运算符则将两个栈顶元素出栈，计算结果，再将结果重新入栈，继续执行$1$。先出栈的是右操作数，最后剩余的就是计算结果。

  • 前缀表达式机算：

    1. 从右往左扫描所有元素，遇到操作数和运算符时执行$2$和$3$。
    2. 遇到操作数则入栈，继续执行$1$。
    3. 遇到运算符则将两个栈顶元素出栈，计算结果，再将结果重新入栈，继续执行$1$。先出栈的是左操作数，最后剩余的就是计算结果。

  • 中缀表达式机算：

    1. 初始化两个栈，操作数栈和运算符栈；
    2. 若扫描到操作数，压入操作数栈；
    3. 若扫描到运算符或界限符，则按照“中缀转后缀”相同的逻辑压入运算符栈（期间也会弹出运算符，每当弹出一个运算符时，就需要操作数栈的两个栈顶元素出栈，计算结果，再将结果重新入栈）。

递归

  函数调用时，最后被调用的函数最先执行结束$(LIFO)$。在函数调用时，会使用栈存储调用返回地址、实参和局部变量。

  递归调用时，函数调用栈称为“递归工作栈”，每进入一层递归，就将信息入栈，每退出一层递归，就将信息出栈。

  • 优点：可以拆分问题规模。
  • 缺点：递归次数过多会导致栈溢出。

特殊矩阵的压缩

数组的存储

  • 一维数组：各数组元素大小相同，且物理上连续存放。下图所示的数组中，若起始地址为$LOC$，则数组元素$a[i]$的存放地址为$LOC+i*sizeof(ELemType),i{\in}[0,9]$。

  • 二维数组：$M$行$N$列的二维数组$b[M][N]$中，按照行优先存储，则$b[i][j]=LOC+(iN+j)sizeof(ElemType)$；按照列优先存储，则$b[i][j]=LOC+(jM+i)sizeof(ElemType)$。

矩阵的存储

  普通的矩阵可以直接使用二维数组存储，特殊矩阵可以压缩空间。

对称矩阵

  $n$阶方阵中，对任意一个元素$a{i,j}$都有$a{j,i}$使得$a{i,j}=a{j,i},i{\not=}j$，则该矩阵为对称矩阵。存储这类矩阵时，可以只存储主对角线$+$上三角区或下三角区。

  • 主对角线$+$下三角区：行优先原则，需要存储$1+2+…+n={\frac{n(n+1)}{2}}$个元素。$a_{i,j}$是第${\frac{i(i-1)}{2}}+j-1$个元素，下标从$1$开始，因此需要减掉。

三角矩阵

  压缩存储策略：与对称矩阵相同，需要多一个存储单元存储常量$c$。

三对角矩阵

  • 主对角线元素下标$i=j$。
  • 从主对角线向左一格，元素下标$i-j=1$。
  • 从主对角线向右一格，元素下标$j-i=1$。
  • 其他元素均为$0$。

  压缩存储策略：使用行优先，只存储带状部分，一共需要存储$3n-2$个元素。

  • 前$i-1$行一共有$3(i-1)-1$个元素，$a{i,j}$是第$i$行第$j-i+2$个元素，$a{i,j}$是第$2i+j-2$个元素。
  • 已知下标$k$，也就是第$k+1$个元素，即$3(i-1)-1<k+1{\le}3i-1$，不等式的结果向上取整可以得到$i$，然后就可以知道$j$的值。

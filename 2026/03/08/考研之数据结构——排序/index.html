排序

基础知识

基本概念

  • 排序：重新排列表中的元素，使表中的元素满足按关键字有序的过程。
  • 输入：$n$个记录$R_1,R_2,…,R_n$，对应的关键字为$k_1,k_2,…k_n$
  • 输出：输入序列的一个重排$R_1^{‘},R_2^{‘},…R_n^{‘}$，使得$k_1^{‘} \le k_2^{‘} \le … \le k_n^{‘}$，或者满足递减顺序。

评价指标

  • 时间复杂度
  • 空间复杂度
  • 稳定性：待排序表中有两个元素$R_i$和$R_j$，其对应的关键字相同，且排序前$R_i$在$R_j$前面。若使用某一排序算法后，$R_i$仍然在$R_j$前面，则该排序算法稳定，否则称该排序算法不稳定。

排序算法的分类

  • 内部排序：数据都在内存中。
  • 外部排序：数据太多，无法全部放入内存。

内部排序算法

插入排序

  每次将一个待排序的记录按关键字大小插入到前面已经排好序的子序列中，直到全部记录插入完成。

  • 空间复杂度为$O(1)$，平均时间复杂度为$O(n^2)$，算法稳定。
  • 使用折半查找找到应该插入的位置，再移动元素。
    • 当$low>high$时折半查找停止，将$[low,i-1]$内的元素全部右移，并将当前元素放到$low$指向的位置。
    • 当$A[mid]==A[0]$时，为保证稳定性，应继续在$mid$的右半区寻找插入位置。

希尔排序

  先将待排序表分割成若干形如$L[i,i+d,i+2d,…,i+kd]$的特殊子表，对各个子表分别进行直接插入排序。缩小增量$d$，重复上述过程，直到$d=1$为止。增量每次减半效率较高。

  • 空间复杂度为$O(1)$，时间复杂度和增量序列的选择有关，最坏为$O(n^2)$，某些情况下可以达到$O(n^{1.3})$。
  • 算法不稳定，只适用于顺序表，不适用于链表。

冒泡排序

  从后往前（或从前往后）两两比较相邻元素的值，若为逆序（$A[I-1]>A[i]$）则交换，直到序列比较完成。下面的题目使用从后往前的顺序比较元素的值。

  以此类推直至最后一趟结束。

  • 空间复杂度为$O(1)$，平均时间复杂度为$O(n^2)$。
  • 算法稳定，可以适用于链表。

快速排序

  在待排序表$L[1…n]$中任取一个元素$pivot$作为基准元素（通常取首元素），通过一趟排序将待排序表划分为独立的两部分$L[1…k-1]$和$L[k+1…n]$，使得第一部分中的元素都小于$pivot$，第二部分中的元素都大于等于$pivot$，则$pivot$在最终位置$L[k]$上。分别递归处理两个子表，重复上述过程直至每部分内只有一个元素或为空，则完成排序。

  继续处理直至全部有序即可。

  • 递归层数可以转化为求二叉树高度的问题，最少为$\lfloor log_2n \rfloor + 1$，最大为$n$。空间复杂度最好为$O(log_2n)$，最坏为$O(n)$；时间复杂度最好为$O(nlog_2n)$，最坏为$O(n^2)$，平均为$O(nlog_2n)$。
  • 优化思路：选头、中、尾三个位置的元素，取中间值作为基准元素。
  • 算法不稳定。

简单选择排序

  每一趟在待排序元素中选取关键字最小的元素加入有序子序列。

  以此类推直至只有一个待排序元素，最后一个无需处理，算法结束。

  • 空间复杂度为$O(1)$，时间复杂度为$O(n^2)$。
  • 算法不稳定，可以适用于顺序表和链表。

堆排序

  若$n$个关键字序列$L[1…n]$满足下面一条性质，则称为堆。

  • 若满足：$L(i) \ge L(2i) \&\& L(i) \ge L(2i+1)(1 \le i \le \frac{n}{2})$，则称为大根堆。
  • 若满足：$L(i) \le L(2i) \&\& L(i) \le L(2i+1)(1 \le i \le \frac{n}{2})$，则称为小根堆。

  每一趟将堆顶元素加入有序子序列（与最后一个元素交换），并将待排序元素调整为大根堆。

  建立大根堆：从下标$i$最大的非终端结点开始，检查是否满足大根堆的要求，若不满足则调整。若元素互换后破坏了下一级的堆，则采用相同方法继续向下调整。

  • 建堆的过程，关键字对比次数不超过$4n$，时间复杂度为$O(n)$。堆排序的空间复杂度为$O(1)$，时间复杂度为$O(nlog_2n)$。

  • 算法不稳定。

堆的插入

  以小根堆为例，新元素放到表尾，与父结点对比。若新元素比父结点更小，则将二者互换，直至遇到更小的元素。

堆的删除

  以小根堆为例，被删除元素用堆底元素替代，然后让该元素不断向下，直到遇见比自己大的元素。

归并排序

  把两个或多个已经有序的序列合并成一个。

  归并排序就是将元素两两归并排序，形成多个序列，然后再进行归并直至剩余一个序列。

  • 每趟归并时间复杂度为$O(n)$，算法需要$log_2n$趟归并，因此时间复杂度为$O(nlog_2n)$，空间复杂度为$O(n)$，来自于辅助数组$B$。
  • 算法稳定。

基数排序

  第一趟按照个位进行排序：

  为了得到递减序列，从个位最大的开始，将元素按照个位递减的顺序排列。

  第二趟按照十位进行排序：

  将元素按照十位递减的顺序排列，由于第一趟的收集，十位相同的元素会按个位递减的顺序排列。

  第三趟按照百位进行排序：

  将元素按照百位递减的顺序排列，由于前两趟的收集，现在所有的元素都按照递减的顺序排列，完成排序。

  • 空间复杂度为$O(r)$，$r$是每个关键字位的可能取值数量；一趟分配$O(n)$，一趟收集$O(r)$，总共$d$趟收集和分配，时间复杂度为$O(d(n+r))$。
  • 适合解决的问题：
    • 数据元素的关键字可以方便地拆分成$d$组，且$d$较小。
    • 每组关键字的取值范围不大，即$r$较小。
    • 数据元素个数$n$较大。

计数排序

  待排序元素的关键字是整数型，元素的取值范围是$[0,k)$。步骤如下：

  1. 创建一个长度为$k$的辅助数组，统计每个元素的出现次数（数组下标对应元素值）。
  2. 再次处理辅助数组，用$C[i]$统计小于等于$i$的元素个数。
  3. 使用数组$C$完成排序，从后往前处理元素，先将数组$C$中对应元素的值减一，然后将该元素放入辅助数组$B$的对应位置，循环直至结束。

  • 空间复杂度为$O(n+k)$，时间复杂度为$O(n+k)$。当$k=O(n)$，计数排序性能较好；当$k>O(nlog_2n)$，计数排序性能较差。
  • 算法稳定。

外部排序算法

归并排序

  最少分配三个缓冲区，将两个磁盘块的内容读入并排序，之后再依次放入输出缓冲区并写回磁盘，即可完成任意大文件的排序。步骤如下：

  1. 生成初始归并段，每个归并段中包含两个磁盘块的内容。
  2. 将初始归并段归并成更大的归并段，并回写磁盘。
  3. 重复该操作直至得到有序文件。

时间开销：读写外存时间$+$内部排序时间$+$内部归并时间。

  优化：通过多路归并，扩展缓冲区数量，提高归并效率，减少磁盘$I/O$次数，但这样会增加内存开销和关键字比对次数。

败者树

  可视为一棵完全二叉树（根结点上面还有一个结点）。$k$个叶结点分别是当前参加比较的元素，非叶结点用来记忆左右子树的失败者，胜者往上继续比较，直至根结点。

  选出了最小元素来自归并段$3$，接下来从归并段$3$中选择下一个元素，并重新一级一级向上对比，直至到达根结点。

  以此类推直到将所有元素变成有序序列，这样对于$k$路归并，选出最小元素只需要对比关键字$\lceil log_2k \rceil$次，比之前的$k-1$次减少很多。

置换-选择排序

  1. 从初始待排序文件$FI$中输入$w$个记录到工作区$WA$。
  2. 从$WA$中选取关键字最小的记录，记为$MINIMAX$记录。
  3. 将$MINIMAX$记录放入初始归并段输出文件$FO$。

  1. 若$FI$不空，则从$FI$输入下一个记录到$WA$。
  2. 从$WA$中所有比$MINIMAX$记录的关键字大的记录中选取最小关键字记录，作为新的$MINIMAX$记录。

  1. 重复$3$~$5$，直至在$WA$中选不出新的$MINIMAX$记录，则当前归并段截止，输出归并段结束标志到$FO$中。
  2. 重复$2$~$6$，直至$WA$为空，得到全部的初始归并段。

最佳归并树

  磁盘$I/O$总次数等于归并树的带权路径长度$WPL*2$，构造二路归并的最佳归并树其实就是构造哈夫曼树。

  多路归并与二路归并类似，选出权值最小的$k$个结点并构造新的父结点，直至全部结点都在树中。

  对于$k$叉归并，若初始归并段数量无法构成严格的$k$叉归并树，则需要补充长度为$0$的“虚段”，再进行$k$叉归并树的构造。最佳归并树是严格的$k$叉树，只有度为$0$和度为$k$的结点。假设度为$k$的结点有$n_k$个，度为$0$的结点有$n_0$个，归并树总结点为$n$，则推导如下：$n=n_0+n_k,kn_k=n-1$（需要减去根结点），由前面两个式子可得$n_k=\frac{n_0-1}{k-1}$。

  • 当$(初始归并段数量-1)\%(k-1)=0$，说明可以构成严格的$k$叉树。
  • 当$(初始归并段数量-1)\%(k-1)=u \neq 0$，说明需要补充$(k-1) -u$个虚段。

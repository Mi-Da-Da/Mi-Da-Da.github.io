数据的表示和计算

数据的表示

进位计数制

  • 基数：每个数码位用到的不同符号的个数，$r$进制的基数为$r$。
  • 位权：数制中每个数位所对应的“权重”，它与该数位的位置相关。

  • 二进制和八进制互相转换：

    • 二进制转八进制：$3$位一组，每组转换成对应的八进制符号。

    • 八进制转二进制：每个八进制符号转换为$3$位的二进制符号。

  • 二进制和十六进制互相转换：

    • 二进制转十六进制：$4$位一组，每组转换成对应的十六进制符号。

    • 十六进制转二进制：每个十六进制符号转换为$4$位的二进制符号。

  • 十进制数转换为二进制：整数部分采用除基取余法，倒序排列余数；小数部分采用乘基取整法，顺序排列整数部分。

  • 八进制和十六进制转二进制时如果位数不够，则整数部分高位补$0$，小数部分低位补$0$。
  • 二进制可以写作$(00100101)_2$或者$00100101B$。
  • 十进制可以写作$(165)_{10}$或者$165D$
  • 十六进制可以写作$(A156)_{16}$或者$A156H$或者$0xA156$。
  • 真值：符合人类习惯的数字。
  • 机器数：数字实际存到机器里的形式，正负号需要被数字化。

定点数和浮点数

  • 定点数：固定的小数点，常规计数。

  • 浮点数：小数点不固定，科学计数法。

  • 无符号数：整个机器字长的全部二进制位均为数值位，没有符号位，相当于数的绝对值。$n$位无符号数表示范围为$0$~$2^n-1$。

  • 有符号数：包括符号位和数值部分。

    • 符号位：$0$代表正，$1$代表负。
    • 数值部分：也称为“尾数”，若机器字长为$n$位，则尾数占$n-1$位。

    • 保存一个小数需要把整数部分和小数部分单独保存，对于整数部分，小数点隐含在最后一位后面；对于小数部分，小数点隐含在符号位后面。

  • 原码：用尾数表示真值的绝对值，符号位$0/1$对应正/负。

    • 若机器字长为$n+1$位，则定点整数的表示范围为$-(2^n-1) \le x \le 2^n-1$，定点小数的表示范围为$-(1-2^{-n}) \le x \le 1-2^{-n}$。
    • 真值$0$有$+0$和$-0$两种形式。
    • $-19$的原码可写为$[X]_原$ =$1,0010011$。

  • 反码：若符号位为$0$，则反码与原码相同；若符号位为$1$，则数值位全部取反。反码是原码转换为补码的中间体。

  • 补码：正数的补码与原码相同，负数的补码是反码末位加一（需要考虑进位）。
    • 补码的$0$只有一种表示，即$00000000$。因此规定补码$1,0000000=-2^7$，补码$1.0000000=−1$。
    • 定点整数的补码比原码多一个$-2^n$，定点小数的补码比原码多一个$-1$。
    • 补码可以把减法操作转变为等价的加法。

  • 移码：补码的基础上将符号位取反，只能用于表示整数。
    • 移码表示的整数可以很方便对比大小。

强制类型转换

  • $C$语言中定点整数使用补码存储。

  • 无符号数和有符号数：不改变数据内容，改变解释方式。

  • 长整数变短整数：高位截断，保留低位。
  • 短整数变长整数：符号扩展。无符号数零扩展，有符号数用符号扩展。
    • 零扩展：适用于无符号整数，用$0$扩展高位。
    • 符号扩展：适用于带符号整数，用符号位扩展高位。

整数的计算

加法器

  • 一位全加器$(FA)$：实现两个一位二进制数的加法。

    • 本位：进行运算的位。
    • 进位：低位加法溢出产生进位。
    • 被加数本位$Ai$，加数本位$B_i$，来自低位的进位$C{i-1}$，本位和$S_i$，向高位的进位$C_i$。
    • 当输入中有奇数个$1$时，本位和为$1$，即$Si=A_i \oplus B_i \oplus C{i-1}$。

    • 当输入中至少有$2$个$1$时，进位为$1$，即$Ci=A_iB_i+(A_i \oplus B_i)C{i-1}$。

  • 并行加法器：两个输入端允许并行输入两个$nbit$数进行加法运算。

    • 串行进位：将$n$个一位全加器串联起来，就可以进行两个$nbit$数的相加。这种方式的进位信息是串行产生的，计算速度取决于进位产生和传递的速度，位数越多越慢。

    • 并行进位：进位信息同时产生，运算速度更快。

  • 带标志位的加法器：在并行加法器的基础上，增加电路逻辑，输出如下的标志位。

    | 标志位 | 翻译 | 作用 | 含义 |
    | :——: | :—————-: | :———————————————: | :————————————————-: |
    | $OF$ | 溢出标志 | 判断带符号数加减运算是否溢出 | $OF=1$溢出，反之未溢出。 |
    | $SF$ | 符号标志 | 判断带符号数加减运算结果的正负性 | $SF=1$表示结果为负，反之结果为正。 |
    | $ZF$ | 零标志 | 判断加减运算结果是否为零 | $ZF=1$表示结果为$0$，反之结果非零。 |
    | $CF$ | 进位/借位标志 | 判断无符号数加减运算结果是否溢出 | $CF=1$溢出，反之未溢出。 |

    • $OF=Cn \oplus C{n-1}$。
    • $SF=S_n$。
    • $ZF=S_n+…+S_2+S_1$。
    • $CF=C{out} \oplus C{in}=C_n \oplus C_0$。

算术逻辑单元ALU

  $CPU$由控制器和运算器组成。控制器负责解析指令，并根据指令功能发出相应的控制信号；运算器负责对数据进行处理。$ALU$是一种组合逻辑电路，实现了加、减、乘、除、与、或、非等功能，是运算器的核心。加减乘除等运算都要基于“加法”实现，因此加法器是$ALU$的核心。

  $ALU$有如下功能：

  • 算术运算：加、减、乘、除等。
  • 逻辑运算：与、或、非、异或、移位等。
  • 其他：求补码、直送等。

  如果$ALU$支持$k$种功能，则控制信号位数$m \ge \lceil log_2k \rceil$。$PSW$寄存器（有时候也叫$FR$寄存器）中存储了标志位的信息，用于展示本次运算结果的特征。

定点数的移位运算

  移位运算：通过改变各个数码位和小数点的相对位置，从而改变各数码位的位权。逻辑移位常用于处理无符号整数，算数移位常用于处理带符号整数。

  • 逻辑移位：
    • 逻辑左移：高位移出丢弃，低位补$0$。对于无符号整数，每逻辑左移一位，就相当于$\times 2$。若逻辑左移丢弃的位为$1$，则发生溢出。
    • 逻辑右移：低位移出丢弃，高位补$0$。对于无符号整数，每逻辑右移一位，就相当于$/ 2$。若逻辑右移丢弃的位为$1$，则会丢弃精度。
  • 算数移位：
    • 算数左移：高位移出丢弃，低位补$0$。对于带符号整数，每算数左移一位，就相当于$\times 2$。若算数左移前后的符号位不同，则发生溢出。
    • 算数右移：低位移出丢弃，高位补符号位。对于带符号整数，每算数右移一位，就相当于$/ 2$。若算数右移丢弃的位为$1$，则会丢弃精度。

定点数的加减运算

  • 原码的加法运算：
被加数+加数 运算规则
正+正 绝对值做加法，结果为正，可能会溢出
负+负 绝对值做加法，结果为负，可能会溢出
正+负 绝对值大的减绝对值小的，符号同绝对值大的数
负+正 绝对值大的减绝对值小的，符号同绝对值大的数

  • 原码的减法运算：减数符号取反，转变为加法。

  • 补码的运算：$[A+B]补=[A]补+[B]补$，$[A-B]补=[A]补+[-B]补$。

    • 正数相加会发生上溢，出现“正+正=负”的情况。
    • 负数相加会发生下溢，出现“负+负=正”的情况。
    • 溢出判断：
      1. 采用一位符号位，$V=A_SB_S \overline{S_S}+\overline{A_SB_S}S_S$，其中运算结果符号为$S_S$。当$V=0$时无溢出，反之则溢出。
      2. 采用一位符号位，根据数据位进位情况判断溢出。符号位的进位$C_S$，最高数值位的进位$C_1$，二者不同表明发生溢出（异或运算实现）。
      3. 采用双符号位，正数符号位$00$，负数符号位$11$。运算后若两个符号位不一致，则发生溢出。
      4. 单符号位补码称为模$2$补码，双符号位补码称为模$4$补码。

无符号数的加减运算

  • 加法：从最低位开始按位相加，并向更高位进位。
  • 减法：被减数不变，减数取反加一，减法变成加法。
  • 无符号数加法运算溢出判断：最高位产生的进位为$1$时，发生溢出。
  • 无符号数减法运算溢出判断：最高位产生的进位为$0$时，发生溢出。

无符号整数的乘法运算

  基本原理：逐位相乘，错位相加。

  • 两个$nbit$无符号数的乘法运算，可拆解为$n$轮加法运算。
  • 根据乘数的各个$bit$，决定每一轮加法运算加被乘数或者加全$0$。
  • 每一轮加法结果与上一轮加法结果需要错位相加。

  $nbit$无符号整数乘法步骤如下：

  1. 开始：被乘数、乘数分别放入寄存器$X$和$Y$，乘积寄存器$P$置为$0$，计数器$C_n$初始值置为$n$（$n$为乘数的位数）。

    • 若被乘数和乘数中有一个为全$0$，则无需运算，结果直接为$0$。

  2. 重复$n$轮加法、移位运算直至计数器为$0$。

    (1) 乘数寄存器$Y$最低位放入控制逻辑进行判断。

    (2) 若最低位为$1$，则执行加法，运算结果写回$P$，进位保存至进位触发器$C$；若最低位为$0$，则什么也不做。

    (3) 将$[C,P,Y]$视为一体，逻辑右移一位。

    (4) 计数器$C_n$减$1$。

  3. 结束：计数器为$0$，乘法结果用$2n$位暂存（寄存器$P$和$Y$），通常只保留低$n$位作为结果。若高$n$位不全为$0$则发生溢出，设置$OF$为$1$，可以忽略也可以执行“溢出自陷指令”。

带符号整数的乘法运算

  • 带有符号，因此可能会有加法和减法。
  • 在$Y$的低位增加一位辅助位。
  • 控制逻辑根据$Y$的最低位和辅助位决定本轮如何处理。
  • 不保存最高位产生的进位。

  $nbit$带符号整数乘法步骤如下：

  1. 开始：被乘数、乘数分别放入寄存器$X$和$Y$，乘积寄存器$P$置为$0$，辅助位置为$0$，计数器$C_n$初始值置为$n$。

    • 若被乘数和乘数中有一个为全$0$，则无需运算，结果直接为$0$。

  2. 重复$n$轮加/减法、移位运算直至计数器为$0$。

    (1) 乘数寄存器$Y$最低位和辅助位放入控制逻辑进行判断。

    (2) 根据寄存器$Y$的最低位和辅助位，决定是$+[x]补$、$-[x]补$或$+0$。

    (3) 将$[P,Y,辅助位]$视为一体，算数右移一位。

    (4) 计数器$C_n$减$1$。

  3. 结束：计数器为$0$，乘法结果用$2n$位暂存（寄存器$P$和$Y$），通常只保留低$n$位作为结果。若高$n+1$位不完全相同则发生溢出，设置$OF$为$1$，可以忽略也可以执行“溢出自陷指令”。

实现乘法运算

  计算机实现乘法运算主要有下面三种方式：

  • 由$ALU$、移位器、寄存器、控制逻辑组成的乘法电路。
    • 实现$nbit$无符号数相乘，至少需要$n$个时钟。可以实现两位乘法，每次处理$Y$末尾的$2bit$，此时仅需$\frac{n}{2}$个时钟。
  • 阵列乘法器：可以在一个时钟内完成乘法运算。

  • 用移位运算、加/减运算等效实现乘法。
    • 优点：在没有乘法运算电路、不支持乘法指令的计算机中，也可以等效实现乘法效果。
    • 缺点：运算速度很慢，每条指令的执行至少需要一个时钟。

无符号整数的除法

  二进制上商规则：商和除数的乘积，要尽可能接近“中间余数”，但不能大于中间余数。

  $nbit$无符号整数除法步骤如下：

  1. 开始：将除数放入寄存器$Y$，被除数放入寄存器$[R,Q]$并完成零扩展，计数器$C_n$初始值置为$n$。

    • 若除数为$0$，则发生“除数为$0$”异常，停止运算并调用操作系统的异常处理程序。
    • 若被除数绝对值小于除数绝对值，则商为$0$，余数=被除数，不必运行除法。
    • 双精度除法$(2nbit / nbit)$可能会出现商溢出，单精度除法$(nbit / nbit)$不会出现商溢出。

  2. 进行$1+n$轮处理，直至计数器为$0$。

    (1) 第一轮特殊处理：直接上商，若第一位商为$1$，则发生商溢出异常，停止除法运算（结果只保留$nbit$）；若第一位商为$0$，则不会发生商溢出。

    (2) 后面$n$轮：先左移，空出的位置用于上商。

    (3) 上商，可能进行加法或减法。

    (4) 计数器$C_n$减$1$。

  3. 结束：计数器为$0$，除法运算结束。寄存器$R$保存余数，寄存器$Q$保存商。

带符号整数的除法

  $nbit$带符号整数除法步骤如下：

  1. 开始：将除数放入寄存器$Y$，被除数放入寄存器$[R,Q]$并完成符号扩展，计数器$C_n$初始值置为$n$。

    • 若除数为$0$，则发生“除数为$0$”异常，停止运算并调用操作系统的异常处理程序。
    • 若被除数绝对值小于除数绝对值，则商为$0$，余数=被除数，不必运行除法。

  2. 进行$n$轮处理，直至计数器为$0$。

    (1) 先左移，空出的位置用于上商。

    (2) 上商：由控制逻辑根据中间余数和除数的符号组合，来决定本轮做减法或加法。再根据$ALU$运算结果的符号位决定上商为$0$或$1$。

    • 新余数与老余数相比，符号不变上商$1$，符号变了上商$0$。

    (3) 计数器$C_n$减$1$。

  3. 结束：计数器为$0$，除法运算结束。寄存器$R$保存余数，寄存器$Q$保存商。

浮点数的计算

IEEE 754 浮点数的表示

  • 科学计数法表示的数由符号、尾数和基数构成。
    • 规格化：确保尾数的最高位非$0$数位刚好在小数点之前。

  • $IEEE{\ }754$标准定义的浮点数格式如下：
    • 还定义了$80bit$的扩展精度浮点型，$16bit$的半精度浮点型、$128bit$的四倍精度浮点型。

  • $float$单精度浮点型的存储：
    • 符号：$0$正$1$负。
    • 尾数：小数点位置在$23bit$之前，默认存储规格化尾数，小数点前的$1$省略。
    • 阶码：用移码表示，规定偏置值为$127$。
      • 十进制真值转偏置值为$M$的移码：将十进制真值+偏置值，然后按无符号整数规则转换指定位数。
    • 基数：无需专门存储，规定基数为$2$即可。
  • $double$双精度浮点型的存储：
    • 符号：$0$正$1$负。
    • 尾数：小数点位置在$52bit$之前，默认存储规格化尾数，小数点前的$1$省略。
    • 阶码：用移码表示，规定偏置值为$1023$。
    • 基数：无需专门存储，规定基数为$2$即可。

浮点数的表示范围

  $IEEE{\ }754$标准规定阶码的范围如下：

  • 当阶码不全为$0$，也不全为$1$，表示这是一个“规格化浮点数”。
  • 阶码全为$0$和全为$1$留作特殊用途。
    • 正无穷大中，符号为$0$，阶码全$1$，尾数全$0$；负无穷大中，符号为$1$，阶码全$1$，尾数全$0$。
    • 正零的符号为$0$，阶码全$0$，尾数全$0$；负零的符号为$1$，阶码全$0$，尾数全$0$。
    • 非数：符号为$0$或$1$，阶码全$1$，尾数不全为$0$，此时为$NaN$。

负数最小 $1,00000000,111..11$ $-0.111..11 \times 2^{-126}$ $2^{-149}-2^{-126}$
负数最大 $1,00000000,000..01$ $-0.000..01 \times 2^{-126}$ $-2^{-149}$
  • 浮点数的上溢：运算结果大于最大规格化正数时称为正上溢，小于绝对值最大的规格化负数时称为负上溢，此时将结果置为$+\infty$或$-\infty$。
  • 浮点数的下溢：运算结果在零和最小非规格化正数之间称为正下溢，在绝对值最小的非规格化负数和零之间称为负下溢，此时将结果置为机器零。

浮点数的加减运算

  1. 对阶：小阶向大阶对齐。
  2. 尾数加减。
  3. 尾数规格化：如果加减后出现类似$0.009527 \times 10^{12}$的情况，需要左规；出现类似$95.27 \times 10^{10}$的情况，需要右规。
  4. 尾数的舍入处理：一般为就近舍入，还有正向舍入、负向舍入以及截断法。就近舍入中，如果$3$个舍弃位是$100$，则需要根据尾数末位判断。尾数末位为$0$，直接截断；末位为$1$，截断多余位，并在末位加一。
  5. 溢出判断。

数据的存储和排列

  • 最高有效字节$(MSB)$：一个数值的最左边字节。
  • 最低有效字节$(LSB)$：一个数值的最右边字节。
  • 大端模式：把最高的有效字节存到更低地址部分，最低有效字节存在较高地址部分，便于人类阅读。
  • 小端模式：与大端模式相反，便于机器处理。
  • 边界对齐：现代计算机按照字节编址，通常也支持按字、按半字、按字节寻址。每次访存只能读/写一个字。

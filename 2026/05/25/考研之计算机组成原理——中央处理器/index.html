中央处理器

CPU的功能和基本结构

  $CPU$的功能包括：

  1. 指令控制：完成取指令、分析指令和执行指令的操作。
  2. 操作控制：一条指令的功能往往是由若干操作信号的组合实现的。$CPU$管理并产生由内存取出的每条指令的操作信号，将其送往相应的部件，从而控制这些部件按要求实现动作。
  3. 时间控制：对各种操作加以时间上的控制。
  4. 数据加工：对数据进行算术和逻辑运算。
  5. 中断处理：对计算机运行过程中出现的异常情况和特殊请求进行处理。

  $CPU$的结构包括运算器和控制器。

  • 运算器：数据加工。
  • 控制器：协调并控制计算机各部件执行程序的指令序列，负责取指令、分析指令和执行指令。
    • 取指令：自动形成指令地址，发出命令。
    • 分析指令：操作码译码，产生操作数的有效地址。
    • 执行指令：根据分析指令得到的操作指令和地址，形成操作信号的控制序列，控制相应设备完成操作。
    • 中断处理：管理总线及输入输出，处理异常情况等。

运算器

  包括算术逻辑单元$(ALU)$和通用寄存器组等。算术逻辑单元和通用寄存器组之间需要建立数据通路以传递数据。

  • 使用多路选择器。
  • 使用三态门。
  • $CPU$内部单总线：将所有寄存器的输入端和输出端都连接到一条公共的通路上，可以通过设置暂存寄存器的方式解决数据冲突现象。

控制器

  包括程序计数器、指令寄存器等。

指令执行过程

  指令周期：$CPU$从主存中取出并执行一条指令所需的全部时间，通常用若干个机器周期表示，一个机器周期又包含若干时钟周期。

  • 取指周期：取指令。
  • 间址周期：取有效地址。
  • 执行周期：执行指令。
  • 中断周期：暂停当前任务去完成其他任务，需保存断点。

  一个指令周期需要包括多个时间段，每次完成指令的一部分功能。指令执行方案有：

  • 单指令周期：所有指令选用相同的执行时间来完成，指令之间串行执行。
  • 多指令周期：不同类型的指令选用不同的执行步骤来完成，指令之间串行执行。
  • 流水线方案：每个时钟周期启动一条指令，尽量让多条指令同时运行，但各自处在不同的执行步骤中，指令之间并行执行。

数据通路

单总线结构

  数据传送包括寄存器之间数据传送、主存与$CPU$之间的数据传送、流向$ALU$的数据。

专用数据通路

控制器

  根据指令操作码、目前的机器周期、节拍信号、机器状态条件，即可确定当前节拍下应当发出的微命令。

硬布线控制器

  设计步骤：

  1. 分析每个阶段的微操作序列。

  2. 选择$CPU$的控制方式。

  3. 安排微操作时序，遵循以下原则：

    • 微操作的先后顺序不得随意更改。
    • 被控对象不同的微操作，尽量安排在一个节拍内完成。
    • 占用时间较短的微操作，尽量安排在一个节拍内完成，并允许有先后顺序。

  4. 电路设计。

    （1）列出操作时间表。

    （2）写出微操作命令的最简表达式。

    （3）画出逻辑图。

  硬布线控制器的特点：

  • 指令越多，设计和实现越复杂，一般用于$RISC$。
  • 扩充一条新的指令较困难。
  • 使用纯硬件实现控制，执行速度较快。微操作控制信号由组合逻辑电路即时产生。

微程序控制器

  • 程序由指令序列组成，微程序由微指令序列组成，每种指令对应一个微程序。
  • 指令是对程序执行步骤的描述，微指令是对指令执行步骤的描述。
  • 微命令与微操作一一对应，微指令中可能包含多个微命令。

工作原理

  如下是微程序控制器的基本结构：

  处理取指周期、间址周期和中断周期的微指令序列都是公用的，执行周期的微指令序列各不相同。取指周期的微指令序列固定从$#0$开始存放，执行周期的微指令序列存放根据操作码指定。

微指令的设计

  • 水平微指令：一条微指令可以定义多个并行的微命令。
    • 优点：微程序短，执行速度快。
    • 缺点：微指令长，编写微程序较麻烦。
  • 垂直型微指令：一条微指令只能定义一个微命令，由微操作码字段规定具体功能。
    • 优点：微指令短、简单、规整，便于编写微程序。
    • 缺点：微程序长，执行速度慢。
  • 混合型微指令：垂直型的基础上增加一些不太复杂的并行操作。

微指令的编码方式

  • 直接编码：微指令的控制字段中，每一位代表一个微操作命令，某位为$1$代表控制信号有效。
  • 字段直接编码：微指令的控制字段分成若干段，每段经译码后发出控制信号，分段原则如下：
    • 互斥性微命令放在同一段，相容性微命令放在不同段。
    • 每个小段包含的信息位不能太多。
    • 每个小段需要留出一个状态，表示该字段不发出任何微命令。
    • 优点：缩短微指令字长。
    • 缺点：需要通过译码电路后发出，比直接编码慢。
  • 字段间接编码（隐式编码）：一个字段的某些微命令需要另一个字段中的某些微命令进行解释。
    • 优点：进一步缩短微指令字长。
    • 缺点：削弱了微指令的并行控制能力。

微指令的地址形成方式

  • 通过下地址字段指出，又称断定方式。
  • 根据机器指令的操作码形成。
  • 增量计数器法，$(CMAR)+1 \rightarrow CMAR$。
  • 分支转移。
  • 通过测试网络。
  • 由硬件产生微程序入口地址。

指令流水线

基本概念

  • 顺序执行方式：$T=n \times 3t=3nt$

    • 优点：控制简单、硬件代价小。
    • 缺点：执行指令的速度较慢，利用率低。

  • 一次重叠执行方式：$T=3t+(n-1) \times 2t = (1+2n)t$

    • 优点：执行时间缩短$\frac{1}{3}$，利用率提升。
    • 缺点：硬件上开销较大，控制过程更加复杂。

  • 二次重叠执行方式：$T=3t+(n-1) \times t = (2+n)t$，与一次重叠相似。

  • 吞吐率：单位时间内流水线完成的任务数量，或者输出结果的数量。

  • 加速比：完成同样一批任务，不使用流水线和使用流水线所用时间之比。

  • 效率：流水线的设备利用率，下图中表现为红色部分和蓝色部分之比。

影响因素和分类

  • 机器周期：将每个阶段的耗时设为一样的，以最长耗时为准。
    • $IF$：取指令。
    • $ID$：译码和取数。
    • $EX$：执行指令。
    • $M$：访问内存。
    • $WB$：写回数据。
  • 流水线每一个功能段部件后面都要有一个缓冲寄存器，称为锁存器，用于保存本流水段的执行结果。

  影响流水线的因素有如下几类：

  • 结构相关（资源冲突）：多条指令在同一时刻争用同一资源而形成的冲突。解决方法如下：
    • 后一相关指令暂停一周期。
    • 资源重复配置：数据存储器+指令存储器。
  • 数据相关（数据冲突）：一个程序中存在必须等前一条指令执行完才能执行后一条指令的情况。解决方法如下：
    • 将遇到数据相关的指令及后续指令都暂停一个或多个时钟周期，直到问题消失后再执行。可以分为硬件阻塞$(stall)$和软件插入$NOP$两种方法。
    • 数据旁路技术。
    • 编译优化，调整指令顺序。
  • 控制相关（控制冲突）：流水线遇到转移指令和其他改变$PC$​值的指令而造成断流。解决方法如下：
    • 转移指令分支预测，分为简单预测或动态预测。
    • 预取转移成功和不成功两个控制流方向上的目标指令。
    • 加快和提前形成条件码。
    • 提高转移方向的准确率。

  流水线的分类如下：

  1. 根据级别不同，可分为部件功能级、处理机级和处理机间级流水线。
  2. 根据功能，可分为单功能和多功能流水线。
  3. 根据同一时间内各段之间的连接方式，可分为静态和动态流水线。
  4. 根据流水线的各个功能段之间是否有反馈信号，可分为线性和非线性流水线。

流水线的多发技术

  • 超标量技术：每个时钟周期内可并发多条独立指令，需配置多个功能部件，不能调整指令的执行顺序。

  • 超流水技术：一个时钟周期内再分段，不能调整指令的执行顺序。

  • 超长指令字：通过编译程序挖掘出指令间潜在的并行性，将多条能并行操作的指令组合成一条具有多个操作码字段的超长指令字。

多处理器

基本概念

  • $SISD$：单指令流单数据流，由一个处理器和一个主存储器组成，若采用指令流水线需要设置多个功能部件，采用多模块交叉存储器。
    • 各指令序列只能并发，不能并行，每条指令处理一两个数据。
    • 不是数据级并行技术。

  • $SIMD$：单指令流多数据流，由一个指令控制部件$(CU)$、多个处理单元、多个局部存储器、一个主存储器组成。每个处理单元有各自的寄存器组、局部存储器和地址寄存器，不同处理单元执行同一条指令，处理不同的数据。
    • 各指令序列只能并发，不能并行，每条指令可同时处理多个具有相同特征的数据。
    • 数据级并行技术。

  • $MISD$：多指令流单数据流，现实中不存在。

  • $MIMD$：多指令流多数据流。

    • 各指令序列并行执行，分别处理多个不同的数据。
    • 线程级及以上并行技术。

    • 多处理器系统：一台计算机内包含多个处理器和一个主存储器。

      • 各处理器之间可以通过$LOAD/STORE$指令访问同一主存储器，并通过主存互相传递数据。
    • 多计算机系统：多台计算机组成。
      • 各计算机之间可以通过“消息传递”互相传递数据。

  • 向量处理机：$SIMD$思想的进阶应用，由多个处理单元、多组“向量寄存器”组成。主存储器采用“多端口同时读取”的多模块交叉存储器，主存储器大小限定了机器的解题规模。
    • 一条指令的处理对象是向量。
    • 擅长对向量型数据并行计算、浮点数运算，常被用于超级计算机中。

考研之计算机组成原理——输入和输出系统

发表于2026-05-25|更新于2026-08-05|考研
|总字数:2.2k|阅读时长:6分钟|浏览量:

输入和输出系统

基础知识

输入输出系统

  • 输入设备：鼠标、键盘。
  • 输出设备：显示器、打印机。
  • 外存设备：硬盘、光盘。
  • $I/O$接口：又称$I/O$控制器、设备控制器，负责协调主机与外部设备之间的数据传输。

I/O控制方式

  • 程序查询方式：$CPU$不断轮询检查$I/O$控制器中的状态寄存器，检测到状态为“已完成”之后，再从数据寄存器中去除输入数据。
  • 程序中断方式：等待键盘$I/O$时$CPU$可以先去执行其他程序，键盘$I/O$完成后$I/O$控制器向$CPU$发出中断请求，$CPU$响应后取走输入数据。
  • $DMA$控制方式：主存与高速$I/O$设备之间的一条直接数据通路，$CPU$向$DMA$接口发出命令，并指明主存地址、磁盘地址、读写数据量等参数。$DMA$控制器自动控制数据读写，每完成一整块数据读写，才向$CPU$发出一次中断请求。
  • 通道控制方式：可以识别并执行一系列通道指令。

I/O接口

I/O接口基础知识

  $I/O$接口有如下功能：

  • 数据缓冲：通过数据缓冲寄存器$(DBR)$达到主机和外设工作速度的匹配。
  • 错误或状态检测：通过状态寄存器反馈设备的各种错误、状态信息，供$CPU$查用。
  • 控制和定时：接收从控制总线发来的控制信号、时钟信号。
  • 数据格式转换：串-并、并-串等。
  • 与主机和设备通信：实现主机—$I/O$接口—$I/O$设备之间的通信。

  $I/O$接口包括内部接口和外部接口。

  • 内部接口：与系统总线相连，实质上是与内存、$CPU$相连。
  • 外部接口：通过接口电缆与外设相连，外部接口的数据传输可能是串行方式，因此$I/O$接口需要具备串/并转换功能。

  $I/O$接口的工作原理如下：

  1. 发命令：发送命令字到$I/O$控制寄存器，向设备发送命令。
  2. 读状态：从状态寄存器读取状态字，获得状态信息。
  3. 读/写数据：从数据缓冲寄存器发送或读取数据，完成主机与外设的数据交换。

I/O端口及编址

  $I/O$端口是指$I/O$接口电路中可以被$CPU$直接访问的寄存器，包括数据端口、状态端口和控制端口。

  • 统一编址：通过不同的地址码区分内存和$I/O$设备，$RISC$机器常用。
    • 优点：不需要专门的输入/输出指令，所有访存指令都可以直接访问控制端口，程序设计的灵活性高。
    • 缺点：端口占用主存地址空间，外设寻址时间长。
  • 独立编址：通过不同的指令区分内存和$I/O$设备，$Intel$常用。
    • 优点：程序编制清晰，$I/O$端口地址位数少，译码速度快，不占用主存地址空间。
    • 缺点：$I/O$指令类型少，程序设计的灵活性差。

I/O方式

程序查询方式

  • 优点：接口设计简单、设备量少。
  • 缺点：$CPU$在信息传送过程中需要花费很多时间用于查询和等待，而且在一段时间内只能和一台外设交换信息，效率低。

中断

基本概念

  中断是指在计算机执行现行程序过程中，出现某些继续处理的异常情况或特殊请求，$CPU$暂时中止现行程序，转去处理异常情况或特殊请求，处理完毕后从断点处继续执行原程序。工作流程如下：

  1. 中断请求：中断源向$CPU$发送中断请求信号。
  2. 中断响应：根据响应中断的条件进行中断判优，确定多个中断处理的先后顺序。
  3. 中断处理：通过中断隐指令或中断服务程序处理。

  中断包括如下几类：

  • 内中断（异常、陷入、例外）：$CPU$内部，与当前执行的指令有关。
    • 自愿中断：系统调用时使用的访管指令，又叫陷入指令。
    • 硬件故障：缺页等。
    • 软件中断：整数除$0$等。
  • 外中断（中断）：$CPU$外部，与当前执行的指令无关。
    • 外设请求：$I/O$操作完成发出的中断信号。
    • 人工干预：用户强行终止一个进程。

  关中断是为了实现原子操作。

  • 可屏蔽中断：关中断时不会被响应。
  • 非屏蔽中断：关中断时也会被相应。

中断请求标记

  每个中断源向$CPU$发出中断请求的时间是随机的，为了记录中断事件并区分不同的中断源，中断系统需对中断源设置中断请求标记触发器$INTR$，当其状态为$1$时表示中断源有请求。

  对于外中断，$CPU$在每条指令执行阶段结束前向接口发出中断查询信号，以获取的中断请求。$CPU$响应中断必须满足以下$3$个条件：

  1. 中断源有中断请求。
  2. $CPU$允许中断（开中断）。
  3. 一条指令执行完毕，且没有更紧迫的任务。

中断判优

  中断判优可以使用硬件和软件实现。

  • 硬件实现：通过硬件排队器实现，既可以在$CPU$中，也可以分散在各个中断源中。
  • 软件实现：通过查询程序实现。

  优先级设计如下：

  1. 硬件故障中断级别最高，其次是软件中断。
  2. 非屏蔽中断优于可屏蔽中断。
  3. $DMA$请求优于$I/O$设备传送的中断请求。
  4. 高速设备优于低速设备。
  5. 输入设备优于输出设备。
  6. 实时设备优于普通设备。

  中断隐指令的任务如下：

  1. 关中断，以保存中断现场不被新的中断所打断。
  2. 保存断点，一般将断点存入堆栈或指定单元。
  3. 引出中断服务程序，即取出中断服务程序的入口地址并传送给$PC$。
    • 软件查询法。
    • 硬件向量法：硬件产生向量地址，通过向量地址找到入口地址。
    • 中断服务程序的任务有：
      • 保护现场。
      • 中断服务。
      • 恢复现场。
      • 中断返回。

多重中断

  • 单重中断：执行中断服务程序时不响应新的中断请求。

  • 多重中断：又称中断嵌套，执行中断服务程序时可响应新的中断请求。

  • 中断屏蔽技术主要用于多重中断，$CPU$要具备多重中断的功能，需满足如下条件：

    • 在中断服务程序中提前设置开中断指令。
    • 优先级别高的中断源有权中断优先级别低的中断源。

    每个中断源都有一个屏蔽触发器，所有屏蔽触发器组合在一起，便构成一个屏蔽字寄存器，屏蔽字寄存器的内容称为屏蔽字。

DMA方式

  $CPU$需要向$DMA$控制器指明要输入还是输出；要传送多少数据；数据在主存、外设中的地址。

  1. 接受外设发出的$DMA$请求，并向$CPU$发出总线请求。
  2. $CPU$响应请求，发出总线响应信号，接管总线的控制权，进入$DMA$操作周期。
  3. 确定传送数据的主存单元地址及长度，并自动修改主存地址计数和传送长度计数。
  4. 规定数据在主存和外设间的传送方向，发出读写控制信号，执行数据传送操作。
  5. 向$CPU$报告$DMA$操作结束。

  如下是$DMA$控制器的结构：

  $DMA$的特点如下：

  1. 它使主存与$CPU$的固定联系脱钩，主存既可被$CPU$访问，也可被外设访问。
  2. 数据块传送时，主存地址的确定、传送数据的计数等都由硬件电路直接实现。
  3. 主存中开辟专用缓冲区，及时供给和接收外设的数据。
  4. $DMA$传送速度快，$CPU$和外设并行工作，提高系统效率。
  5. $DMA$在传送开始之前要通过程序进行预处理，结束后通过中断方式进行后处理。

  $DMA$传送方式：

  1. 停止$CPU$访问主存。
  2. $DMA$与$CPU$交替访存。
  3. 周期挪用。
